# Summer Essentials Store

## Purpose
Summer Essentials Store is a modern summer eCommerce platform where users can browse seasonal products, view product details, and access protected product pages after login.

## Live Link
https://assignment8-b13.vercel.app/

## Key Features
- Responsive navbar with Home, Products, My Profile, Login, Register, Avatar, and Logout
- Home page with summer sale banner
- Popular products section showing 3 products
- Products page showing all 6 products
- Protected product details page
- Login and register pages
- My Profile page showing logged-in user information
- Update profile feature
- Footer with contact info, social links, and privacy policy
- Summer Care Tips section
- Top Brands section
- Animation using Animate.css

## NPM Packages Used
- Next.js
- React
- Tailwind CSS
- Animate.css
